## 截断字幕复核与原片时标跳转

- 基线：`main` `7203ad5`（PR #3 已合并）。
- 目标：当手工切点穿过某句字幕导致其被部分截断时，在界面展示复核提示条，说明有多少句被切点截断并已从成片字幕略去，并提供按钮一键跳回原片对应句段起始时间。
- 验收：
  - `tests/review-hint.test.mjs` 覆盖 `partialReview`：无截断或整句剪除时不展示提示；存在截断时按字幕顺序统计数量并格式化提示文案（「N 句被切点截断，已从成片字幕略去。」）与跳转标签（「定位 mm:ss.mmm」）。
  - `web/review-hint.js` 模块导出 `partialReview`，`server/index.mjs` 提供静态路由。
  - `tests/browser.mjs` 验证手动切入字幕时出现 `#review` 提示条与跳转按钮，点击后播放器跳转至原片时标，导出成片 SRT 验证省略截断字幕，撤销剪辑后提示条重新隐藏。
- 本轮不做：词级切点微调；改变 `core/` 字幕重排策略；多机位。

## 恢复项目源校验与撤销深度状态反馈

- 基线：`main` `f806c3e`（PR #4 已合并）。
- 目标：恢复 `.transcript-cut.json` 项目文件时，在状态栏明确反馈源视频校验结果以及当前可撤销历史步数；错源恢复被拒绝时明确说明当前编辑保持未改动。
- 验收：
  - `tests/restore-status.test.mjs` 覆盖 `restoreStatus`：非同源项目返回「项目与当前视频不匹配，请先导入同一个原视频。当前编辑未改动。」；同源项目返回「源视频校验通过。转写稿、剪点和撤销记录已恢复。」并准确附加「可撤销 N 步。」或「当前没有可撤销的编辑。」。
  - `web/restore-status.js` 模块导出 `restoreStatus`，`server/index.mjs` 提供静态路由。
  - `tests/browser.mjs` 冒烟断言错源 JSON 拒绝后状态栏包含「当前编辑未改动」，同源恢复后状态栏包含「源视频校验通过」与「可撤销 2 步」。
- 本轮不做：跨视频强行合并编辑历史；改动项目 JSON 结构；修改 `duration_us`。

## V3.0-A · 编辑工作区视觉收紧

- 基线：`main` `9d610ce`（PR #5 已合并）。
- 目标：规范编辑器视觉排版与交互体验：采用系统中文无衬线字体栈，统一间距、阴影和按钮层级；视频预览区使用深色底仓；时间轴加宽并区分保留段与剪除段样式；切段在悬停或获得焦点时展示当前位置与时标；提供跟随系统首选并可本地持久化记忆的浅色/深色主题切换。
- 验收：
  - 页面启动根据系统 `prefers-color-scheme` 或 `localStorage` 恢复主题（`dataset.themeReady`）。
  - `tests/browser.mjs` 验证深色与浅色模式下预览底仓亮度（< 0.25）与文字对比度（> 0.65），验证主题切换按钮即时生效、跨刷新持久化并在清理存储后恢复跟随系统。
  - 时间轴高度保持在 16px–24px 范围；保留段与剪除段渲染不同样式（背景色/条纹）；悬停与聚焦切段时 `#timeline-readout` 呈现「当前位置」文案与保留/剪除区间时标。
- 本轮不做：拖放导入；快捷键说明弹窗；未保存离开提示；修改剪辑核心算法。

## V3.0-B · 拖放导入

- 基线：`main` `b748262fada3c2cd2dadae742f3916a7baa3ed27`（PR #6 已合并）。当时没有未合并 PR，远端分支也没有比 `main` 更新的编辑器改动。
- 目标：把 MP4、SRT 或项目 JSON 拖进窗口。导入路径与「导入 MP4」「导入 SRT」「恢复项目」相同，成功和失败都写进 `#status`。
- 验收：
  - 未导入视频时拖入 SRT 或 JSON 被拒绝，剪辑状态不变。
  - 无法识别的类型，以及一次拖入多个文件，被拒绝。
  - 伪装成 MP4 的无效文件被拒绝，且不替换当前素材。
  - 拖入合法 MP4 后出现预览；再拖入落在片长内的 SRT 出现句段。
  - 错源项目 JSON 被拒绝且当前句段不变；同源 JSON 恢复。
  - 已有编辑时，拖入会替换转写稿，沿用原来的确认框；取消则句段不变。
  - 现有 `npm test` 与无模型浏览器冒烟保持通过，并覆盖上述拖放。
- 本轮不做：快捷键说明、建议类型分色、未保存离开提示、转写/导出进度、窄屏重排、词级剪辑、多机位。不改 `duration_us`，不执行 `moon publish`。

## 未保存编辑保护与离开提示

- 基线：`main` `b748262`（PR #6 已合并）。与 PR #7 并行开发，在 PR #7 之前合入主干（合并提交 `eada39e`）。
- 目标：防止用户误触导致剪辑进度丢失：当存在尚未保存至项目文件的剪辑（剪切、修字或撤销）时，导入新视频、新字幕或恢复项目前弹窗确认；刷新或关闭网页时触发浏览器原生 `beforeunload` 离开提示。保存成功或同源恢复后清除未保存脏状态。
- 验收：
  - `tests/edit-dirty.test.mjs` 覆盖 `editSignature`、`isEditDirty`、`saveNoticeClearsDirty`、`restoreNoticeClearsDirty` 与 `leavePromptNeeded`；撤销回初始状态判定为未脏，修字和剪切判定为脏，仅无错误的成功保存与恢复才重置脏标记。
  - 替换转写稿使用「替换转写稿会清空当前编辑，继续吗？」；未保存替换提示「当前编辑尚未保存，继续会清空这些编辑，要继续吗？」，取消则提示「已取消，当前编辑未改动。」。
  - `tests/browser.mjs` 覆盖存在脏编辑时打开样例或刷新页面触发确认弹窗及 beforeunload；取消后保留当前编辑，保存成功后刷新不再提示。
- 本轮不做：本地自动存盘；跨标签页同步；自动草稿箱。

## 转写与导出真实阶段反馈

- 基线：`main` `2064a45`（PR #11 已合并）。
- 目标：弃用估算的虚假百分比进度显示，改用后端真实经历的任务阶段（`stage`）：导出阶段包含「正在核对保留片段」（`check`）、「正在编码成片，完成时间不确定」（`encode`）、「正在保存成片和字幕」（`write`）；转写阶段包含「正在本机转写，完成时间不确定」（`transcribe`）、「正在整理转写结果」（`finish`）；未知阶段安全回退为「正在处理，完成时间不确定」。在独立横幅（`#job-banner`）展示阶段与不确定动画，保留状态栏内容；连接或解析异常时明确提示并解锁导出。
- 验收：
  - `tests/job-status.test.mjs` 验证 `jobStageText` 针对导出和转写各类阶段输出真实文案且不含 `%` 字符；验证 `jobPollError` 区分网络断开与 JSON 解析异常并给出可读提示。
  - `tests/service.test.mjs` 验证真实导出任务返回 `stage: 'write'` 且最终进度为 1。
  - `tests/browser.mjs` 拦截轮询模拟编码中阶段横幅展示、模拟失败后横幅清除与错误提示，并最终跑通真实导出全流程。
- 本轮不做：基于编码帧数的真实百分比精算；任务队列管理；多任务并发处理。
